# Project 01: Building a Neural Network Adding Machine

## Overview

This project implements a Feedforward Neural Network (FNN) that learns to add two integers. The model takes two numbers as input and predicts their sum as output.

## Objective

The goal of this project is to understand the complete deep learning workflow, including:

* Dataset generation
* Neural network design
* Model training
* Model evaluation
* Result visualization

## Dataset

* Input 1: Integer between -10 and +10
* Input 2: Integer between -10 and +10
* Target: Sum of the two integers

### Example

| Input 1 | Input 2 | Output |
| ------- | ------- | ------ |
| 4       | 5       | 9      |
| -3      | 7       | 4      |
| -8      | -2      | -10    |

## Model Architecture

* Input Layer: 2 Neurons
* Hidden Layers: Fully Connected Dense Layers
* Activation Function: ReLU
* Output Layer: 1 Neuron
* Optimizer: Adam
* Loss Function: Mean Squared Error (MSE)

## Technologies Used

* Python
* Pytorch
* NumPy
* Matplotlib
* Scikit-learn

## Results

The neural network successfully learned the addition operation and achieved high prediction accuracy on unseen test data.
